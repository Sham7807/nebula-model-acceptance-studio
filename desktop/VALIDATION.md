# 桌面版验证记录

验证日期：2026-09-24。环境：Apple Silicon，macOS 26，Swift 6.3.3。所有新增操作使用本地模拟渠道与合成媒体，没有调用用户的付费模型。

## 1.1.0 更名与亮白界面

同步网站提交 `eb343dd`，桌面版更名为「渠道测试系统」。46 个网页资源与引擎模块按桌面名称替换和报告主题追加规则核对，业务源码与网站一致。

- 网页回归：171 项 JavaScript、390 项 Python 和 334 项 subtests 通过；1 项 Python 跳过。首次与打包并行运行时一条 socket 收尾时限断言超时，专项 39 项和完整顺序复跑均通过；未放宽测试阈值。
- 桌面引擎：5 项集成测试通过，报告接口验证新名称、亮白主题、评级、耗时与清单内容。
- 原生 WebKit：49 项检查通过，涵盖 10 个工作区、模型获取、历史保存和三类媒体。
- 人工检查：概览、文本、通用检测、Claude 专项、设置窗口；统一控件高度、选择框指示、弹窗及卡片圆角。新版仍使用系统文件选择与保存窗口。
- 数据升级：实际安装在 `/Applications/渠道测试系统.app`；保留旧应用备份，更新前后的 2 条测试记录内容摘要完全一致。Bundle ID、钥匙串标识和数据目录保持不变。
- 分发：1.1.0 / build 4 的 Swift release 构建、嵌套签名和 DMG 校验通过。纯亮白外观不跟随系统深色，轻量动效支持减少动态效果设置。

## 1.0.2 同步验证

同步网站提交 `8d3bf2e`，43 个顶层网页资源与引擎模块与网站源码逐一比对一致。

- 网页回归：171 项 JavaScript、320 项 Python 和 301 项 subtests 通过；1 项 Python 跳过。
- 桌面引擎：5 项集成测试通过。打包后报告接口确认资源评级可用，单条成功样本仍标注「暂定 · 证据待完善」。
- 原生 WebKit：49 项断言 / 检查通过，包含全部工作区、模型获取、历史保存及图片 / 音频 / 视频预览。
- 分发：1.0.2 / build 3 的应用签名与 DMG 校验通过；替换应用时保留旧版备份，不修改用户数据目录。
- 安装后启动：原生概览显示 1.0.2 和「本地引擎就绪」。

## 1.0.1 同步验证
