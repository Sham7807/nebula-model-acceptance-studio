# 桌面版验证记录

验证日期：2026-09-24。环境：Apple Silicon，macOS 26，Swift 6.3.3。所有新增操作使用本地模拟渠道与合成媒体，没有调用用户的付费模型。

## 1.0.2 同步验证

同步网站提交 `8d3bf2e`，43 个顶层网页资源与引擎模块与网站源码逐一比对一致。

- 网页回归：171 项 JavaScript、320 项 Python 和 301 项 subtests 通过；1 项 Python 跳过。
- 桌面引擎：5 项集成测试通过。打包后报告接口确认资源评级可用，单条成功样本仍标注「暂定 · 证据待完善」。
- 原生 WebKit：49 项断言 / 检查通过，包含全部工作区、模型获取、历史保存及图片 / 音频 / 视频预览。
- 分发：1.0.2 / build 3 的应用签名与 DMG 校验通过；替换应用时保留旧版备份，不修改用户数据目录。
- 安装后启动：原生概览显示 1.0.2 和「本地引擎就绪」。

## 1.0.1 同步验证

同步网站提交 `325e7d3`，网页与服务端业务源码保持一致。打包资源逐一比对：43 个顶层网页资源与引擎模块与源码完全相同。

- 网页回归：164 项 JavaScript、310 项 Python 和 301 项 subtests 通过；1 项 Python 跳过。
- 桌面引擎：5 项集成测试通过，新增打包后 `/api/reports` 导出验证，确认结论与耗时、模块总览、末尾清单及共用样式均可用。
- 原生 WebKit：49 项断言 / 检查通过，包含全部 10 个工作区、模型获取、历史保存及三类媒体播放。
- 分发：1.0.1 / build 2 的应用签名与 DMG 校验通过。版本显示直接读取应用元数据。
- 安装后启动：原生概览显示 1.0.1 和「本地引擎就绪」，正式数据目录保持原位。报告内容通过端点集成检查，本轮未新增报告截图验收。
