# 桌面版验证记录

验证日期：2026-09-24。环境：Apple Silicon，macOS 26，Swift 6.3.3。所有新增操作使用本地模拟渠道与合成媒体，没有调用用户的付费模型。

| 范围 | 证据与结果 |
| --- | --- |
| 原生构建 | Swift release 构建成功；无需完整 Xcode 工程 |
| 本地引擎 | 5 项集成测试通过：鉴权 / CSRF、私有数据权限、跨启动保留历史、独立端口、重复实例保护、stdin 关闭退出及内置 Python |
| 原生 WebKit | 49 项断言 / 检查通过：全部 10 个工作区路由、渠道同步、四类入口模型发现、模拟文本请求、数据库保存、图片 / WAV / H.264 预览 |
| 人工操作 | 原生连接窗口、图生图文件选择与缩略图、报告保存窗口与文件落盘、设置窗口、安装后启动、退出后无残留引擎 |
| 外观 | 实际检查原生概览、基础与通用工作区、Claude 专项以及浅 / 深色外观；针对深色模式补齐旧组件表面颜色 |
| KVV 依赖 | 固定上游版本素材 4/4 校验通过；kimi-k3 预检加扩展收集 25 个参数化节点，全套收集 611 个节点；仅收集，没有执行付费请求 |
| 原有网页 | 150 项 JavaScript 检查通过；284 项 Python 检查通过、1 项跳过，297 项 subtests 通过 |
| 分发 | 自包含应用约 122 MB，压缩 DMG 约 63 MB；嵌套代码签名校验和 DMG 校验通过；应用复制到用户 Applications 后可独立启动 |

可复现命令见 [README](README.md#验证)。临时测试日志在本机构建目录 `desktop/qa/`，不提交测试数据库、密钥、运行时和安装包到源码仓库。
